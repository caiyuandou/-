# 听课本 · 第一阶段学生版 Demo

## 已实现
- 本地音频导入、浏览器播放，支持 MP3/WAV/M4A/WEBM/OGG/FLAC，最大 24 MB。
- 明确标注的高中物理示例：课程概览、知识点、易错提醒、原文、自测和 Markdown 报告导出。
- 本机 Node 服务：音频真实转写 → 带来源索引的学习报告 → 点击时间回听。未配置密钥时禁用真实分析，不会拿示例冒充结果。
- 手机与电脑响应式页面；本页临时状态，不保存学生音频或报告。

## 启动本机完整版
需要 Node.js 22 或更高版本。没有第三方 npm 依赖。

1. 将 `.env.example` 复制为 `.env`，由项目负责人在本地配置自己的服务密钥，不要把密钥发送到聊天或放到浏览器。
2. 运行 `node --env-file=.env server.mjs`。
3. 在浏览器打开 `http://127.0.0.1:4317`。没有密钥也可以运行 `node server.mjs` 体验示例。
4. 页面显示“AI 服务已配置”表示服务端已配置密钥，不代表密钥额度已验证。导入实际课堂录音，填写课程名和关注点，然后点击生成。

线上 Sites 版本是静态演示：支持本地导入、播放、示例、自测、导出，但不含本机 Node 后端，也不能分析真实音频。上线真实分析需部署带鉴权的后端并配置服务凭证。

## 数据与限制
点击生成才会将音频通过本机后端发送给 OpenAI API。转写结果继续用于报告生成。音频与结果只在内存中处理；页面刷新即丢失，需提前导出。未实现用户体系、历史课程、自动蓝牙同步、长录音切片、后台队列或持久化。已有外部录音设备可手动导出并导入，无须厂商 SDK。

示例为手写预置课堂文本，没有配套录音；示例出处显示片段号，真实报告显示转写时间点。报告不能断定学生的个人掌握情况，练习不自动评分。

## 演示顺序
1. 打开示例课堂，展示课程概览和核心知识点。
2. 点击“原文片段”，展示结论能回到原文核对。
3. 打开自测，先思考再展开参考答案。
4. 导出报告。
5. 导入录音笔导出的真实文件并播放；配置 AI 后演示真实分析。

## 第一阶段验收
尚需用真实课堂录音验收：检查关键公式和数字、逐条核对来源、确认题目和答案与本课有关。当前未配置 API 密钥，因此没有完成真实模型端到端验证。

接口依据：[OpenAI 文件转写](https://developers.openai.com/api/docs/guides/speech-to-text)、[Responses API](https://developers.openai.com/api/reference/cli/resources/responses/methods/create)。
