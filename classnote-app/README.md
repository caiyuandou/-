# 听课本 · 独立学习网页
这是普通 Node.js + HTML/CSS/JavaScript 应用，不使用 Sites，没有云托管依赖，不需要安装 npm 包。需要 Node.js 22.13+（推荐本机已有的 24）。

## 启动
双击「启动听课本.cmd」，或在此目录运行：
node server.mjs

打开 http://127.0.0.1:4321 。服务运行时保持启动窗口开启；关闭即停止。已经启动时无需重复运行。

## 已实现
- 学习总览：真实课程、练习次数、已完成任务。
- 课程：新建、搜索、学科筛选、可恢复归档。
- 录音：本机保存、播放、拖拽导入，支持 MP3/WAV/M4A/OGG/WEBM/FLAC，单文件 200 MB。
- 原文：粘贴文字，导入 TXT/MD/SRT/VTT，保存和编辑；有时间戳可跳转回听，无时间戳仅按原文片段核对。
- DeepSeek：真实课程摘要、知识点、关键概念、易错提醒、自测、记忆卡和基于课程的答疑。
- 我的笔记：个人笔记独立保存，AI 生成不会覆盖。
- 自测与错题：服务端评分，错误自动收集，重做答对后移出错题本。
- 记忆卡：查看答案、自评已记住或需复习。
- 复习计划：手动创建、从报告建议添加、关联课程、完成与撤销完成。
- 学习记录：近 7 天提交次数、正确率、已完成计划。预计学习时长不当作实际计时。
- 导出：课程报告、练习答案和个人笔记导出为 Markdown。

## 连接真实服务
1. 在网页「AI 设置」填写自己的 DeepSeek API Key，模型默认 deepseek-flash，可按账户可用模型修改。
2. 点击保存，再点击测试连接（会产生一次简短真实请求）。
3. 新建课程，保存课堂文字，点击「生成学习笔记」。
4. 若需要从录音自动转文字，另填硅基流动 API Key。已适配 FunAudioLLM/SenseVoiceSmall、TeleAI/TeleSpeechASR 的文件转写接口。DeepSeek 密钥不能代替另一家服务的密钥。
5. 录音 → 转写 → 核对原文 → 生成笔记 → 自测/答疑 → 安排复习。

不提供密钥也能实际使用课程、录音、文字、个人笔记和任务管理。AI 功能会明确提示缺少配置，不生成伪造结果。
也可通过环境变量 DEEPSEEK_API_KEY / SILICONFLOW_API_KEY 配置。

## 数据
SQLite 数据库在 data/classnote.sqlite；录音在 data/audio。密钥 AES-GCM 加密保存，解密密钥也在本机 data/.key，拥有本机数据访问权限的人仍可能读取。数据库和录音不会自动上传。只有转写、生成或问答操作会把相应内容发送到指定服务。
备份时先关闭服务，再复制整个 data 文件夹。不要只复制数据库而漏掉音频和密钥文件。

## 范围
当前是本机单用户网页。不是公网多用户服务，尚无账户登录、跨设备同步、手机直连、计费或自动蓝牙同步。若部署到公网，应先增加账户鉴权、用户数据隔离、HTTPS、限额和后台队列，而不是直接开放本机端口。
单节课堂文字上限 60000 字，超限明确拒绝，长课应分成多节。语音服务限额与支持格式以提供商实际返回为准。更新原文会清空旧 AI 报告、自测和记忆卡；历史答题记录保留用于统计。
归档课程不会删除数据。替换录音会保留旧文件用于恢复，但旧文件不再在界面展示。
AI 数字、公式和结论需核对；系统不根据录音推断学生个人能力。

## 飞书接入（本机演示版）

设置页新增飞书配置，App ID 按已提供的应用链接预填。App Secret 和用户凭证加密保存在本机，不回传浏览器。

1. 在应用后台添加重定向 URL：`http://127.0.0.1:4321/api/feishu/callback`。访问网页时统一使用 127.0.0.1。
2. 设置页填写 App Secret、飞书云空间目标文件夹链接，保存后点击连接飞书并完成授权。
3. 课程中上传录音，点击生成飞书课堂记录；稍后点击获取生成结果。
4. 飞书摘要和转写保存后，DeepSeek 可继续生成教育学习报告。

上传使用 files/upload_all（不超过 20 MB）或 prepare/part/finish 分片接口。本版网页沿用 200 MB 音频上限。获取结果会替换课堂原文并清空旧 AI 练习，个人笔记保留。生成请求结果不明时停止重复提交，需先在飞书核对。设置修改后需重新授权。授权有效期结束且未取得刷新凭证时需重新连接。

已用模拟响应测试 OAuth state、浏览器绑定、重复回调拒绝、分片上传、重复提交去重、生成中状态、导入及密钥不回传。真实账户授权和录音联调尚需完成。当前仅为本机单用户演示，所有课程共用一个飞书账户；不适合直接部署为多学生服务。

## 学生版课堂报告
课程默认展示课堂学习报告。未配置 DeepSeek 时可查看飞书摘要和章节预览；配置后生成学习目标、知识点、原文例题、老师原话、待核对项、自测和复习任务。学习阶段及关注点可在“我的笔记”调整。老师原话须与引用片段一致，例题与目标保留原文索引，旧报告仍可查看。生成会调用已配置的 DeepSeek 服务，飞书原始记录独立保留。

本机音频导入上限 200 MB，上传按块写入磁盘；飞书大文件逐片读取上传。硅基流动直接转写仍受 50 MB、1 小时限制。
